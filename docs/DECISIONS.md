# Engineering decisions

- 2026-11-07: retain prototype in history and source reference; new runtime mounts none of its insecure Vercel handlers. One persistent Fastify process serves SPA, browser and Twilio WebSockets. Active sockets are process-bound, durable records live in Postgres.
- pnpm workspace, React 18/Vite, Fastify, Drizzle/Postgres and pg-boss. Queue shares Postgres; QStash and Redis are unnecessary.
- Read Gnani index and current STT streaming, TTS SSE, languages, voices and Agent Builder model documentation before implementing adapters. Endpoint `wss://api.vachana.ai/stt/v3/stream`, `x-api-key-id`, signed PCM16LE mono, exactly 1024 bytes paced at 64ms for 8kHz. `processing` indicates speech end, `transcript` is final; do not invent partial events. Timbre SSE `https://api.vachana.ai/api/v1/tts/sse`, `X-API-Key-ID`, `chunk.audio` base64, `complete` event. `container:mulaw` forces 8kHz. v3.0 voice Shivani is documented multilingual. Use explicit language codes.
- Gnani now documents an Agent Builder API and model configuration. This implementation intentionally owns the conversation and uses a separately configured Sarvam/OpenAI-compatible text model; Prisma and Timbre supply speech only. Agent Builder is not used and no claim is made about Evon.
- Defaults select Gnani. Offline mode requires explicit `MOCK_MODE=true`; never automatically switch to mocks on provider failure. Mock output is marked simulation throughout.
- Recording stays disabled. Persist redacted transcript text, not raw audio. HR sensitive utterances are dropped before persistence/model history using conservative filtering; this is a defense, not a guarantee of comprehensive sensitive-data detection.
- Fly official region list currently includes Singapore `sin`, not Mumbai: https://docs.fly.io/reference/regions . Choose Singapore provisionally; measure network latency after credentials and deployment exist. No nearest-endpoint latency claim.
- Compliance is conservative: 09:00–21:00 Asia/Kolkata outer window, stricter campaign windows only. No registry scrubbing is claimed. National DLT/NCPR/TRAI obligations belong to the operator.
- Live credentials, actual provider measurements, managed backup configuration and public deployment require human-owned accounts. Record unrun checks explicitly.
