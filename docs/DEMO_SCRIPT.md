# 60-second demo shot list

Record only after choosing **live verified** or **explicit simulation** mode. Keep the mode badge visible. A simulation recording is an engineering walkthrough, not a qualifying live Gnani speech demonstration. No real candidate/customer data may appear.

| Time | Shot | Honest narration |
|---|---|---|
| 0–8s | Overview → New campaign → HR & Recruitment | “We configure a calling campaign with disclosure and approved facts.” |
| 8–18s | Job title, role summary, explicit screening question and expected answer | “Screening uses only job-related criteria. Humans decide hiring outcomes.” |
| 18–27s | Agent/voice preview, opening AI disclosure, synthetic CSV | “Prisma recognizes speech and Timbre supplies voice. [Name actual configured LLM] handles dialogue.” |
| 27–35s | Test allowlist, operator attestation, review | “Every phone dial checks suppression, consent attestation, hours and caps.” |
| 35–48s | Browser test with monitor, ask one screening question | Live: show actual microphone/Gnani audio and provider trace. Offline: say “This is a scripted text simulation with silent mock audio.” Never dub synthetic audio as live. |
| 48–55s | Candidate result, advisory eligibility, destination delivery | Show real receiver acceptance only after a verified signed test. Otherwise say “Saved internally; external receiver setup pending.” |
| 55–60s | Analytics with real/sample filter visible | “These charts derive from stored records. Simulations stay separate from live metrics.” |

Use a pre-created **synthetic** draft if six wizard steps exceed the minute; do not pretend it was generated from no input. Show a browser call without a phone number for judges. Do not claim Google Sheets, WhatsApp, warm transfer, production concurrency, zero hallucinations or nationwide compliance. Record a new live run once credentials are available; the repository currently has no live-provider evidence.
